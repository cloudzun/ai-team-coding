# 指标口径表

> 适用于 `homestay.db`（模拟数据）。单元二问答与单元三巡检共用这一份。回答里的每个指标都按本表计算；本表没有的指标，先说明口径再算。

## 1 基础约定

| 编号 | 约定 | 说明 |
|---|---|---|
| C-01 | 订单晚数 | 一笔订单占用 `checkin_date` 到 `checkout_date` 前一天的每一晚；`nights` = 两者相差天数 |
| C-02 | 订单归属月份 | 订单按**入住日（`checkin_date`）所在月份**整笔归属，跨月订单不拆分 |
| C-03 | 在线期间 | 房源从 `online_date` 当天起可售；`offline_date` 当天及以后不可售；`offline_date` 为空表示仍在线 |
| C-04 | 关房晚数 | `owner_blocks` 的 `start_date`、`end_date` 都包含在内：关房晚数 = `end_date − start_date + 1` |
| C-05 | 已完成订单 | `bookings.status = '完成'`；`'取消'` 的订单不计晚数和收入 |
| C-06 | 比例的写法 | 库内计算结果用 0–1 的小数；对用户展示可换成百分数，并保留一位小数 |
| C-07 | 时间范围 | 数据覆盖 2023-10-01 至 2026-09-30 |

## 2 指标

| 编号 | 指标 | 口径 |
|---|---|---|
| M-01 | 可售晚数 | 当月天数 − 房东关房晚数（`owner_blocks`），只计在线期间（C-03、C-04） |
| M-02 | 成交晚数 | 已完成订单的晚数之和（C-01、C-02、C-05） |
| M-03 | 入住率 | 成交晚数 ÷ 可售晚数 |
| M-04 | 平均房价 | 已完成订单总额 ÷ 已完成订单晚数 |
| M-05 | 每间可售房收入 | 已完成订单总额 ÷ 可售晚数 |
| M-06 | 取消率 | 取消订单数 ÷ 全部订单数（按入住日归属期间） |
| M-07 | 平均评分 | 当期评论总评分（`reviews.rating`）的算术平均，空值不计；有效评分少于 5 条时标“样本不足”，不给数值结论 |
| M-08 | 子评分 | 清洁、入住、沟通、位置、描述相符、性价比六项，各自取算术平均，空值不计；样本规则同 M-07 |
| M-09 | 与市场差距 | 自己的指标 − `market_benchmark` 同区、同房型、同月的对应指标；比较价格时用自己的“平均房价”对“市场均价 `avg_price`”，比较入住率时用 M-03 对 `occupancy_rate` |
| M-10 | 渠道占比 | 某渠道订单数 ÷ 全部订单数（含取消单）；只看完成单时须注明 |
| M-11 | 在线房源数 | 当期内至少有一天处于在线期间的房源数 |

## 3 名词

| 编号 | 名词 | 定义 |
|---|---|---|
| T-01 | 空置 | 只指“可售但没人订”的晚数 = 可售晚数 − 成交晚数。**房东关房不算空置。** |
| T-02 | 当前价格 | `price_history` 中该房源生效日期不晚于当天的最新一行；平日价对周日至周四晚，周末价对周五、周六晚 |
| T-03 | 同比 | 与上一年同一月份或同一期间比较 |
| T-04 | 环比 | 与紧邻的上一期比较 |

## 4 参考写法：按月入住率

可售晚数需要按天展开再扣除关房。下面是一种写法，可以按需改时间范围和分组：

```sql
WITH RECURSIVE days(d) AS (
  SELECT '2025-01-01' UNION ALL SELECT date(d, '+1 day') FROM days WHERE d < '2025-12-31'
),
sellable AS (
  SELECT l.listing_id, l.district_id, substr(days.d, 1, 7) AS ym, COUNT(*) AS sellable_nights
  FROM listings l
  JOIN days ON days.d >= l.online_date AND (l.offline_date IS NULL OR days.d < l.offline_date)
  WHERE NOT EXISTS (SELECT 1 FROM owner_blocks b
                    WHERE b.listing_id = l.listing_id AND days.d BETWEEN b.start_date AND b.end_date)
  GROUP BY l.listing_id, ym
),
sold AS (
  SELECT listing_id, substr(checkin_date, 1, 7) AS ym, SUM(nights) AS sold_nights, SUM(total_amount) AS revenue
  FROM bookings WHERE status = '完成' GROUP BY listing_id, ym
)
SELECT s.ym, ROUND(1.0 * COALESCE(SUM(so.sold_nights), 0) / SUM(s.sellable_nights), 4) AS occupancy
FROM sellable s LEFT JOIN sold so ON so.listing_id = s.listing_id AND so.ym = s.ym
GROUP BY s.ym ORDER BY s.ym;
```
