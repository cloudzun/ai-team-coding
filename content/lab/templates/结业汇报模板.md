# 结业汇报模板（一页）

汇报只讲三件事：任务书哪一栏改过，G2 放行凭什么，没做到什么；再带上迭代方向一页。邻组只追问，不打分。每个字段写一两句，能指到记录的就指到记录。

组名：______　　汇报日期：______　　讲的人：业务 ______　分析 ______　技术 ______

| 字段 | 本组填写 |
|---|---|
| **单元与来源** | 讲的是单元 ____。任务书与记录是：本组自己做的 / 存档点上的（二选一，写明哪个存档点） |
| **要证明的一件事** | 照抄栏 2 的第一句： |
| **改过的一栏与原因** | 取自任务书末尾“迭代记录”的一行：改了栏 __，因为（现象）：<br>如果没改过：我们判断过栏 __，没改的原因： |
| **放行三问** | 一　检查命令跑过两次、我们读过：命令是 ______（谁跑的 ______），正向绿在 `evidence/user-check.md` “命令与输出”那一节的哪一行 ____。<br>二　坏夹具变红：红的是哪一行 ______。<br>三　人眼三问和结论是我们自己写的：我们亲眼看的是 ______，在“人眼”那一节的第几行 ____，结论一行写的是 ______。 |
| **没做到的** | 至少一条，取自 `L1-QA.md` 里未解决的缺陷或“没做到的”： |
| **迭代方向** | 我们挑的方向：______。我们预判接它最难写的是栏 __，因为： |
| **对邻组追问的回应** | 追问原话：<br>我们的回应：<br>指向的记录（抽验记录的哪一块 / `L1-QA.md` 的哪一条 / 迭代记录的哪一行）： |

## 汇报前，三人互相核对一遍

- [ ] 每个“放行三问”的回答，都能在记录里指出对应的那一节，不凭记忆讲。
- [ ] “没做到的”至少有一条，且是我们自己的记录里写着的。
- [ ] 本组判例已写：下次遇到 ______，就做 ______。来自单元 __ 的 ______。
