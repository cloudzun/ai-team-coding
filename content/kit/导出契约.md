# 页面导出契约 `window.__chartExport()`

本文件是课程导出契约的唯一真相源。任务书、需求、规格、技能和检查脚本里凡是涉及“页面怎么把图表数据交出来”，都按本文件；别处写法与本文件不一致，也按本文件。

## 1 页面要提供什么

页面提供全局函数 `window.__chartExport()`，同步返回或返回 Promise 均可，结果是一份可转成 JSON 的对象：

```json
{
  "page": "dashboard",
  "filters": {"district": "全公司"},
  "kpis": [{"id": "occupancy_latest", "value": 0.6123, "label": "61.2%"}],
  "charts": [
    {
      "id": "occ_monthly",
      "title": "按月入住率",
      "series": [
        {"name": "本期", "points": [{"x": "2026-01", "value": 0.6123, "label": "61.2%"}]}
      ]
    }
  ]
}
```

## 2 字段规则

- 顶层字段固定为 `page`、`filters`、`kpis`、`charts`。`filters` 写当前筛选状态，联动后随之变化。`kpis` 可以是空数组。
- 图表点位固定为 `charts[].series[].points[]`，每点 `{x, value, label}`。字段名只用 `points`，不用 `data`、`values` 等别名；检查脚本读到别名会报“系列 … 的 points 不是数组”，判红。
- `kpis[]` 每项至少 `{id, value, label}`，可以附加 `yoy`、`mom` 等字段，检查脚本不检查附加字段。
- 对象 `id` 与系列名由需求或规格列清单；参考 SQL 的段头 id、系列名与导出里的逐字一致，写法见第 6 节。

## 3 比例与差值：一律 0–1 小数

- 比例类数值（入住率、占比、同比变化率等）的 `value` 一律用 0–1 小数，不写百分数。页面显示“61.2%”，导出的 `value` 是 0.6123。
- 差值也用 0–1 小数：同比的百分点差，用两个小数相减的结果（0.05 就是 5 个百分点）。
- 金额、评分等非比例数取原值。
- 把百分数（例如 63.7）写进 `value`，检查脚本按 0–1 判，会超差；指标卡的 `label` 软核对也会报警告。

## 4 `value` 与 `label` 的含义

- `value` 是机器值：取自已渲染的图表实例（例如图表库当前配置）或页面上渲染出来的节点，不能把后端接口的原始数据直接转发。否则图装反了，导出的数据仍然“正确”。
- `label` 是页面上实际显示的文字（如“61.2%”）；取不到时写 `null`。
- 两者并存：显示用百分数，`value` 仍是 0–1 小数；不要把显示值塞进 `value`。

## 5 怎么导出

页面打开后，在浏览器控制台执行下面这一行，把粘贴出来的内容存成 `export.json`：

```js
copy(JSON.stringify(await window.__chartExport()))
```

`await` 是因为函数可以返回 Promise。

## 6 参考 SQL 的写法（给写规格的人）

参考 SQL 是页面各项数字的期望值来源。检查脚本读它、只读地执行它，再与页面导出的数据逐点对。写规格的人按这一节写，脚本才读得进去。

**文件与分段**

- 一个文件放多段查询。每段前面一行注释声明对应的对象：`-- chart: <id>` 或 `-- kpi: <id>`；`<id>` 与导出里的对象 id 逐字一致。
- 第一个声明之前只留注释，不写 SQL；段的内容到下一段声明为止。
- 段与段之间不共享临时表：两段要用同一份取数，各写一遍。

**段返回什么**

- `chart` 段返回三列，列名顺序固定：`series`（系列名）、`x`（横轴类目）、`value`（数值）；同一系列同一 `x` 只能出现一行。
- `kpi` 段返回一行一列：`value`。

**段头的可选项**

- `-- unit: ratio` / `-- unit: money` / `-- unit: other` 指明这一段的数值类别，决定用哪把容差；评分这类非比例数写 `unit: other`。
- `-- tol: 0.005` 为这一段单独指定容差，覆盖默认值。
- 可选项写在声明行上，或写在该段第一句 SQL 之前的注释里。

**只放查询**

文件里只允许 SELECT（含 `WITH`）。出现 INSERT、UPDATE、DELETE、CREATE、DROP、ALTER、ATTACH、REPLACE、PRAGMA 这类写语句时，脚本拒绝运行。

**默认容差**

- 比例（`ratio`）0.001，金额（`money`）0.01 元；`other` 用比例那把，也是 0.001。
- 比例类的值一律用 0 到 1 的小数，不写百分数。参考 SQL 的 `value` 与页面导出的 `value` 是同一把尺；页面显示的百分数在导出的 `label` 里，不在 `value` 里。

**选区对账另写一份**

- 除全公司版 `ref.sql`，另写一份选区对账用的 `ref_d08.sql`，对的是选区之后的那一份导出（`filters` 里是区名）。
- 联动只改“选区后会变的对象”：指标卡、按月入住率、房型结构加区条件；对比图本来就是 8 个区并列，那一段不加区条件，原样保留全公司版的写法，仍是 8 个区。
- 对比图那一段误加了区条件，选区对账会报“多余点”或“缺失点”。

导出的形状本身不在这一节，见第 1 至 5 节。
